# ОМДЖЕТ ГидроЛог — инструкция оператора

Версия программы: **0.1.0**. Автор: Andrew Kena, OMJET.

Здесь описаны функции, которые есть в ГидроЛоге и которых нет в обычном QGroundControl. Интерфейс переведён на русский; подключение, планирование заданий и настройка автопилота устроены так же, как в QGroundControl.

---

## 1. Запуск

1. Запустите `OMJETGidroLog.exe` (или ярлык после установки).
2. В заголовке окна должно быть **«ОМДЖЕТ ГидроЛог 0.1.0_ДД.ММ.ГГГГ»**: версия и сегодняшняя дата.
3. При первом запуске Windows спросит доступ к сети. Выберите **«Частные сети» → «Разрешить»**.

У ГидроЛога свои настройки, они не смешиваются с OMJET AERO и QGroundControl.

### Меню (иконка слева вверху)

| Пункт | Что открывает |
|---|---|
| **КАРТА** | основной экран работы с лодкой |
| **ЗАДАНИЕ** | планирование маршрута съёмки |
| **АНАЛИЗ** | логи, MAVLink Inspector |
| **ПАРАМЕТРЫ СУДНА** | настройка автопилота |
| **НАСТРОЙКИ ПРОГРАММЫ** | настройки ГидроЛога |
| **ВЫХОД** | закрыть программу |

## 2. Подключение через пульт Skydroid H16 Pro

На сам пульт программа не ставится: на нём Android 7.1, а нужен Android 9+. Пульт работает радиомостом к ноутбуку или планшету.

1. Включите лодку и пульт, дождитесь связи.
2. Подключите ноутбук к Wi-Fi-точке пульта или кабелем в его Ethernet-порт.
3. На пульте включите передачу MAVLink по UDP на IP ноутбука, порт **14550**.
4. Лодка должна подключиться сама.
5. Если не подключилась: **НАСТРОЙКИ ПРОГРАММЫ → Каналы связи → Добавить → UDP** с нужным портом.

## 3. Верхняя панель

**Слева:** `статус │ 💬 │ режим │`

| Статус | Значение |
|---|---|
| **Не подключено — нажмите, чтобы подключиться** | лодки нет на связи |
| **Не готов** | предстартовые проверки не пройдены — нажмите на статус, чтобы увидеть причины |
| **Готов** | можно запускать |
| **Запущен** | лодка заармлена |
| **На ходу** | лодка заармлена и движется |
| **Нет связи** | пропала телеметрия |

- 💬 — значок сообщений с борта (оранжевый — есть предупреждения, красный — ошибки). Появляется, когда есть сообщения.
- Режим автопилота пишется текстом (Hold, Auto, Manual…).

**Справа:**

| Индикатор | Что показывает |
|---|---|
| **Спутники** | число спутников, HDOP и **координаты лодки**. По нажатию — «GPS борта» и «Статус RTK GPS» с настройками RTK |
| **Телеметрия** | `-65 / -70 дБм` — сигнал на пульте и на борту; `потери 0.3%`. Больше 5% — оранжевым. По нажатию — «Состояние телеметрии» |
| **Батарея** | процент, **напряжение крупно**, ток А и израсходовано мА·ч. По нажатию — «Батарея 1» (состояние, остаток, напряжение, израсходовано, температура) |

## 4. Панель управления (слева)

Кнопки, которые меняют состояние лодки, срабатывают только после **удержания 2 секунды**. Пока держите, кнопку заполняет полоска. Если отпустить раньше, ничего не произойдёт.

| Кнопка | Действие |
|---|---|
| **ЗАПУСК** | удержание 2 с — арм; ещё раз 2 с — дизарм. Пока лодка заармлена, фон **красный** |
| **СТОП** | **сразу по нажатию** — аварийная остановка моторов. Лодка остаётся заармленной, кнопка **мигает красным** и называется **«СНЯТЬ СТОП»**. Чтобы снять стоп, удерживайте её 2 с |
| **РУЧНОЕ УПРАВЛЕНИЕ** | удержание 2 с — ручной режим |
| **ВЫПОЛНЕНИЕ ЗАДАНИЯ** | удержание 2 с — выполнение задания |
| **УМНЫЙ ВОЗВРАТ** | удержание 2 с — возврат по пройденному пути |
| **ВОЗВРАТ** | удержание 2 с — возврат к точке старта |

- **Текущий режим** подсвечен **зелёным**.
- **Сирена и мигалка** (значки внизу панели) становятся **оранжевыми**, когда включён назначенный канал на пульте. Каналы задаются в настройках (раздел 10).

> ⚠️ Если на пульте тумблер назначен на «Motor Emergency Stop» (`RCx_OPTION = 31`), он и кнопка СТОП управляют одной функцией: действует последнее переключение.

## 5. Правая панель

Правый верхний угол: **Скорость**, **Пройдено**, **Температура** воды, **Глубина**.

- **«--»** — данных нет.
- **Оранжевая глубина** — эхолот вне рабочего диапазона (обычно мельче 0,5 м), цифре доверять нельзя.
- **Пройдено** обнуляется при каждом запуске (арме).
- Единицы измерения настраиваются в **НАСТРОЙКИ ПРОГРАММЫ → Общие → Единицы измерения**.

### Цвет значений

Нажмите на любое значение — откроется окно **«… — цвет значения»**:

1. Включите **«Раскрашивать по диапазонам»**.
2. Задайте до трёх диапазонов **от … до …** в единицах панели и выберите цвет (зелёный, жёлтый, оранжевый, красный, голубой, белый).
3. Пустое поле — без ограничения. Если диапазоны пересекаются, берётся первый подходящий.
4. **«Сохранить»** — настройки сохраняются после перезапуска.

Пример для глубины: от пусто до **1,5** — красный; от **1,5** до **3** — жёлтый; от **3** до пусто — зелёный.

## 6. Приборы (справа внизу)

- **ТАНГАЖ** — катер сбоку. Нос вверх — силуэт наклоняется носом вверх.
- **КРЕН** — катер спереди. Крен на правый борт — силуэт наклоняется вправо.
- Шкала ±40°: **жёлтая** часть для положительных углов, **голубая** для отрицательных. Под силуэтом точное значение в градусах.
- **Компас:** подписи в градусах **0, 45, 90 … 315** (0 — север, жёлтым), деления через 11,25°. В середине — катер по курсу, под ним текущий курс в градусах.

**Сообщения с борта** (оранжевое окно) появляются над этими приборами. Они переведены на русский, например «Предстарт: Компас не откалиброван», «Аварийная остановка моторов». Нажмите на окно, чтобы закрыть его.

## 7. Карта

### Значки и линии

| Что | Значение |
|---|---|
| Красный силуэт катера | положение лодки, нос по курсу |
| **Оранжевая** линия от носа | текущий курс лодки |
| **Голубая** линия | курс на текущую точку задания (видна в арме) |
| **Зелёная** сплошная линия | маршрут задания |
| **Красные** круги | точки срабатывания затвора камеры |

Если оранжевая и голубая линии расходятся, лодку сносит течением или ветром.

### Трек, раскрашенный по глубине

| Цвет | Глубина |
|---|---|
| красный | мелко: минимум шкалы и мельче |
| жёлтый → зелёный → голубой | от мелкого к глубокому |
| синий | глубоко: максимум шкалы и глубже |
| серый | эхолот не дал глубину |

### Карта глубин (как на эхолотах Lowrance)

- По мере движения лодки растёт **цветная заливка дна** в тех же цветах, что и трек.
- Возле трека (до 8 м) заливка строится всегда; **между соседними галсами** (до 30 м) — если замеры есть с нескольких сторон.
- Кнопка **«Карта глубин»** в легенде скрывает и показывает заливку.
- Карта хранится в памяти до отключения лодки или закрытия программы.

### Точки с подписями глубины

- С выбранным интервалом на треке ставится точка с подписью, например «5.73 м». Жёлтая — норма, оранжевая — эхолот вне диапазона.
- Подписи видны **при приближении карты**.

### Когда стираются трек и точки

- при новом **запуске (арме)**;
- при **загрузке задания** на борт или **скачивании** его с борта;
- при отключении лодки или закрытии программы.

### Окно видео

Если видеопотока нет, вместо картинки с камеры показывается заставка с надписью **«НЕТ ВИДЕО»**.

### Завершение задания

Когда задание выполнено, появляется окно **«Задание выполнено»**: **«Удалить задание с борта»** или **«Оставить задание на борту»**.

---

## 8. Легенда глубин (слева вверху)

1. **Мин / макс.** Введите число и нажмите **Enter**. Трек и карта глубин сразу перекрасятся. Подбирайте под водоём: для глубин 2–6 м поставьте **2** и **6**.
2. **Ползунок подписей** — как часто ставятся точки с глубиной: от 2 до 60 с. **Крайнее правое положение — «выкл»**.
3. **«Карта глубин»** — включает и выключает заливку дна.

---

## 9. Планирование задания (ЗАДАНИЕ)

### Верхняя панель

| Кнопка | Действие |
|---|---|
| **Открыть** | открыть файл задания |
| **Сохранить** | сохранить в файл |
| **Загрузить на борт** | отправить задание на лодку |
| **Скачать с борта** | забрать задание с лодки |
| **Очистить** | удалить все точки (и с борта) |
| **☰** | Сохранить как..., Сохранить KML |

### Кнопки слева

- **Полигон** → «Создать полигон:» **Площадной объект** (галсы по площади) или **Линейный объект** (вдоль линии).
- **Точка** — включить добавление точек кликом по карте.
- **Возврат** — добавить возврат к точке старта в конец задания.

У полигона на карте: **Прямоугольник**, **Окружность**, **Многоугольник** (кликайте вершины, затем **«Готово»**), **Загрузить KML/SHP**.

### Слои (справа сверху)

**Задание**, **Забор Безопасности** (зона, за которую лодке нельзя выходить), **Резервный порт** (запасные точки возврата).

### Правая панель

- **Шаблоны задания** (новое задание): Площадной объект, Линейный объект, Без шаблона.
- **Параметры по умолчанию:** скорость хода для новых точек, ожидаемые скорости судна для расчёта времени.
- **Задание · N точек** — список точек. Карточка точки: название команды (Путевая точка, Возврат, Ожидание…) и её параметры (Ожидание, Радиус достижения…). Меню **⋮**: Перенести к борту, Перенести к предыдущей точке, Изменить координаты....
- **Преобразование:** сместить, перенести или повернуть всё задание.

Внизу — **статистика задания** (длина, время). Кнопка **«<<»** сворачивает её.

### Запуск задания

После загрузки на борт: **ЗАПУСК** (2 с) → **ВЫПОЛНЕНИЕ ЗАДАНИЯ** (2 с), либо кнопка **«Начать задание»** на карте.

## 11. Настройка эхолота на лодке (справка)

Скрипт `APM/scripts/m36.lua` на Cube Orange+. Параметры автопилота:

| Параметр | Значение |
|---|---|
| `SCR_ENABLE` | 1 |
| `SERIAL2_PROTOCOL` / `SERIAL2_BAUD` | 28 (Scripting) / 115 |
| `RNGFND1_TYPE` / `RNGFND1_ORIENT` | 36 (Scripting) / 25 (вниз) |
| `FRAME_CLASS` | 2 (лодка): ArduRover шлёт `WATER_DEPTH` |

- **Глубина** берётся из `WATER_DEPTH`, а если его нет — из `DISTANCE_SENSOR`.
- **Температура** приходит как `NAMED_VALUE_FLOAT "M36TEMP"`.
- Скрипт пишет CSV на SD-карту: `APM/LOGS/M36_….CSV`.

## 12. Тренировка на симуляторе (только Debug-сборка)

1. **НАСТРОЙКИ ПРОГРАММЫ → Mock Link → ArduPilot → APM ArduRover Vehicle → Start**. Лодка появится в точке 55.040686, 73.128945.
2. **ЗАДАНИЕ → Полигон → Площадной объект:** полигон к востоку от лодки, расстояние между галсами 10–30 м → **Загрузить на борт**.
3. **КАРТА:** удерживайте **ЗАПУСК** 2 с, затем **ВЫПОЛНЕНИЕ ЗАДАНИЯ** 2 с. Лодка пойдёт со скоростью ~2 м/с.
4. **СТОП** остановит лодку без дизарма; удержание 2 с снимет стоп, и лодка продолжит задание.

| Где (от старта) | Рельеф дна |
|---|---|
| 120 м на запад | берег |
| у старта | ~5,7 м |
| 50 м на северо-восток | яма до ~11 м |
| 60 м на юго-запад | отмель |
| 100 м на восток | русло |

## 13. Если что-то не работает

| Проблема | Что проверить |
|---|---|
| Лодка не подключается | связь с пультом, UDP на IP ноутбука, Firewall, канал UDP в настройках |
| Статус «Не готов» | нажмите на статус — там список причин; сообщения «Предстарт: …» в оранжевом окне |
| Глубина «--» | идут ли `WATER_DEPTH` / `DISTANCE_SENSOR` (**АНАЛИЗ → MAVLink Inspector**); есть ли сообщение «M36: драйвер запущен» |
| Температура «--» | есть ли `NAMED_VALUE_FLOAT` `M36TEMP` |
| Трек серый, карта не строится | глубина не приходит или эхолот вне диапазона |
| Трек и карта одного цвета | сузьте мин/макс в легенде |
| Между галсами дыры | галсы дальше ~60 м друг от друга — сделайте их чаще |
| Нет подписей глубины | приблизьте карту; ползунок не в положении «выкл» |
| Кнопка не срабатывает | режимы и ЗАПУСК — удерживать 2 с |
| СТОП не останавливает | не перебивает ли тумблер пульта с `RCx_OPTION = 31` |
| Сирена/мигалка не горят | назначены ли каналы и порог в **«Дополнительно»** |
| Сообщение по-английски | для этого текста ещё нет перевода — сообщите разработчику |
